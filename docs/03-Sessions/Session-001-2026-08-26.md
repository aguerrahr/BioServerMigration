## Decisiones Tomadas

| Decisión | Justificación | Consecuencias |
|----------|---------------|---------------|
| API REST en lugar de migrar directamente | Rápido, seguro, escalable | Sigue dependiendo de VB6 |
| Migrar módulos de menor a mayor complejidad | Aprendizaje, validación, riesgo | ServerSave al final |
| Usar Dapper en lugar de EF Core | Control, rendimiento, simplicidad | Más código manual |
| Usar System.Text.Json | Rendimiento, nativo, estándar | Menos flexibilidad |
