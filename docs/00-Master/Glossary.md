# Glosario de Términos - BioServer Migration

## A
- **ABIS**: Automated Biometric Identification System. Sistema automatizado de identificación biométrica.
- **ADR**: Architecture Decision Record. Documento que registra una decisión arquitectónica importante.

## B
- **BioKey**: Identificador único de un sujeto biométrico en el sistema.
- **BB**: Backup Bio. Archivos de respaldo de datos biométricos (extensión .bb).

## C
- **COM**: Component Object Model. Tecnología de Microsoft para componentes reutilizables.
- **CORS**: Cross-Origin Resource Sharing. Mecanismo para compartir recursos entre dominios.

## D
- **Dapper**: Micro-ORM para .NET, usado para acceso a datos.
- **DLL**: Dynamic Link Library. Biblioteca de enlace dinámico.

## H
- **HBIE**: Motor biométrico utilizado (probablemente Neurotechnology o similar).
- **HTTP**: Hypertext Transfer Protocol. Protocolo de comunicación web.

## I
- **IIS**: Internet Information Services. Servidor web de Microsoft.
- **JSON**: JavaScript Object Notation. Formato de intercambio de datos.

## M
- **Mermaid**: Lenguaje para crear diagramas desde texto.

## P
- **Payload**: Datos enviados en una solicitud HTTP.
- **Pool**: Conjunto de instancias reutilizables de un objeto.

## R
- **REST**: Representational State Transfer. Estilo arquitectónico para APIs web.
- **RSA**: Algoritmo de cifrado asimétrico.

## S
- **STA**: Single-Threaded Apartment. Modelo de concurrencia de COM.
- **SOAP**: Simple Object Access Protocol. Protocolo de servicios web.

## T
- **TTN**: Temporal Transaction Number. Identificador de transacción temporal.
- **TT**: Temporal Transaction. Transacción temporal en el sistema.

## V
- **VB6**: Visual Basic 6. Lenguaje de programación.
- **VB.NET**: Visual Basic .NET. Versión moderna de VB.

## W
- **WS**: Web Service. Servicio web.
- **Wrapper**: Capa de fachada que envuelve otra funcionalidad.
